# Gambit fixture corpus

These files are committed output, not inputs: regenerate them, never hand-edit them.

`gambit-16.6.0.json` is generated by `scripts/gen_fixtures.py` from the six catalog games, three known degenerate cases, and 30 deterministic random games. Its own `provenance` block records the solver command, Gambit version, container image and its immutable local ID, source seed, and the `--network=none` / no-bind-mount conditions it ran under; the sibling `manifest.json` records the case count and the SHA-256 digest of the exact committed bytes.

The generator evaluates each game in a disposable container with `--network=none`, no bind mounts, a read-only root filesystem, all Linux capabilities dropped, `no-new-privileges`, a non-root user, resource limits, and an in-memory `/tmp`. Inputs enter only through standard input and output returns only through standard output. The image build downloads public Gambit v16.6.0 sources and Debian build packages; it does not receive repository content.

Build the pinned local image, then generate the corpus:

```sh
docker build --tag gt-sandbox/gambit-enummixed:16.6.0 tools/gambit
python3 scripts/gen_fixtures.py
```

The generated output is an external cross-oracle, not a replacement for the engine's own hand-authored catalog oracles and independent verifier.

## Evolution presets

`evolution-presets.json` is the calibration record for the evolution presets. Each preset
pins the complete seeded match environment, its estimated per-round payoff
matrix, final population shares after 100 discrete replicator generations, and
a named threshold predicate. Tests rerun every configuration and require an
exact matrix/endpoint match before the associated product copy can ship.

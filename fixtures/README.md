# Gambit fixture corpus

`gambit-16.3.0.json` is generated by `scripts/gen_fixtures.py` from the six catalog games, three known degenerate cases, and 30 deterministic random games. Its manifest records the source seed, Gambit version, immutable local image ID, case count, and SHA-256 digest.

The generator evaluates each game in a disposable container with `--network=none`, no bind mounts, a read-only root filesystem, all Linux capabilities dropped, `no-new-privileges`, a non-root user, resource limits, and an in-memory `/tmp`. Inputs enter only through standard input and output returns only through standard output. The image build downloads public Gambit v16.3.0 sources and Debian build packages; it does not receive repository content.

Build the pinned local image, then generate the corpus:

```sh
docker build --build-arg SOURCE_DATE_EPOCH=1752537600 --tag gt-sandbox/gambit-enummixed:16.3.0 tools/gambit
python3 scripts/gen_fixtures.py
```

The generated output is an external cross-oracle, not a replacement for the engine's own hand-authored catalog oracles and independent verifier.

## Evolution presets

`evolution-presets.json` is P8's reviewed calibration record. Each preset
pins the complete seeded match environment, its estimated per-round payoff
matrix, final population shares after 100 discrete replicator generations, and
a named threshold predicate. Tests rerun every configuration and require an
exact matrix/endpoint match before the associated product copy can ship.

The build pins the Debian base and its package snapshot to inputs available by 15 July 2025, and verifies the upstream Gambit source archive checksum. The explicit source-date build argument fixes image timestamps for reproducible builds; a rebuild can be performed later.
